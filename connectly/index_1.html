How to Play

Every board has a handful of numbered dots scattered across the grid. Press and drag from dot 1 to draw a path across the cells, reaching each numbered dot in order — 1, then 2, then 3, and so on.

The path can only move between cells that share an edge — never diagonally — and it can never cross or revisit a cell. Drag back over your own path to erase the end of it.

It isn't solved just by reaching every number — the path has to cover every single cell on the grid, with none left empty, ending on the highest number. Reach the last one and the path stops there — it won't let you keep going past it.

A new Connectly unlocks every day at midnight UTC. The grid stays 6×6; the number of stops varies.
